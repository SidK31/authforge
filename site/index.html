What AuthForge is working toward

Secure passwords

Passwords are handled with a memory hard password hashing approach instead of storing the original secret.

Sessions

Refresh tokens will be rotated and tracked so compromised sessions can be revoked.

Authorization

Roles and permissions will be enforced on the server, not trusted from client supplied values.

Security testing

Abuse cases and common authentication failures will be tested and documented as the project grows.
